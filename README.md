# vloader

一款基于 Android 原生 API 实现的 HLS（M3U8）下载与播放工具。本页为当前版本的完整功能说明。

| 项目 | 说明 |
|---|---|
| 包名 | `com.vloader.app` |
| 版本 | 1.1 |
| 运行环境 | Android 8.0（API 26）及以上，适配至 Android 16（API 36） |
| 实现 | Java + Android SDK，零第三方依赖、无广告；界面由原生 View 代码构建 |

---

## 一、链接输入与校验

| 能力 | 说明 |
|---|---|
| 链接录入 | 手动粘贴；剪贴板检测到链接时自动提示，点击即填入输入框 |
| 批量任务 | 多行输入，一行一条，按队列顺序自动完成 |
| 自定义命名 | 支持 `链接\|文件名` 语法，下载前即可指定输出文件名 |
| 注释行 | 行首 `#` 视为备注，不参与下载 |
| 真实性校验 | 先校验 URL 形态，再确认响应内容含 `#EXTM3U` 与 `#EXT-X-` 标签，非 HLS 播放列表不予下载 |

---

## 二、在线预览

内置基于 `MediaPlayer` 的播放器，直接播放在线流，不写入本地文件、不占用存储空间。播放器控件全部自绘。

- 全屏按视频原始宽高比铺放，画面不拉伸；横屏时自动旋转
- 倍速播放；长按进入 3 倍速，松手恢复原速
- 前后 10 秒跳转、上一条 / 下一条切换
- 可交由设备上其他播放器打开

---

## 三、下载引擎

**并发与调度**

- 默认 32 线程并发，线程数可自定义或设为无限制；另可配置「单次下载文件数」并发上限
- 网络波动时自动重试；断点续传复用已下载片段，续下无需重头开始
- 整批任务共享令牌桶，按总带宽限速

**HLS 解析**

- 支持主列表 / 子流、`BANDWIDTH` 与 `RESOLUTION` 属性、`#EXT-X-KEY`（AES-128）、`#EXT-X-MEDIA-SEQUENCE`、`#EXT-X-DISCONTINUITY`、`#EXT-X-ENDLIST` 等标签
- 相对 URL 通过 `URI.resolve` 解析，并处理 BOM 与 URI 百分号编码
- 解析主列表时自动选取带宽最高的子流
- AES-128 加密流解密后按序合并

**网络与后台**

- 自定义 `Key: Value` 请求头，可设置 `Referer`、`Cookie`、`User-Agent` 等，适配需要校验来源的站点
- 前台服务配合 `WakeLock`，切出应用或锁屏后持续下载
- 通知栏展示进度、速度、剩余时间，并提供暂停 / 继续 / 放弃操作；完成时推送系统通知
- 任务页可暂停、继续、取消，进度与已下载片段数实时刷新

## 四、输出与存储

- **封装**：通过系统 `MediaExtractor` + `MediaMuxer` 将拼接后的 TS 重封装为标准 MP4 容器，逐轨复制编码数据，不转码、不损失画质。产物可被系统相册、即时通讯应用与网页直接打开，进度条可自由拖动
- **保存位置**：公共下载目录 / `Download` 子文件夹 / 自定义绝对路径，三种模式可选
- **内置文件管理器**：浏览目录、逐级返回、新建文件夹，选定目录即时生效

---

## 五、下载历史

按「已下载 / 正在下载」双栏组织。每条记录支持：

打开、重命名、复制到、移动到、删除文件、仅移除记录、复制链接。

默认打开方式通过 `queryIntentActivities` 枚举设备上全部可处理视频的应用，可每次询问或指定默认应用。

## 六、界面与外观

- **主题**：Material You（MD3）/ MIUI 两套风格，浅色 / 深色 / 跟随系统
- **字号**：小 / 标准 / 大 / 超大四档，全局统一缩放
- **壁纸**：自定义图片铺满内容层，叠加遮罩保证文字对比度
- **底部导航**：悬浮形态与液态玻璃材质为两个独立开关，可组合出经典固定、悬浮磨砂、悬浮液态玻璃三种形态。玻璃层基于 `RenderEffect.createBlurEffect` 对下层内容做实时背景模糊，配合 Fresnel 边缘高光、表面流光与弹簧物理滑动指示器
- 首次启动展示用户协议，关于页可随时再次查看
